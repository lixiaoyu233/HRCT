# 纤护呼吸公益项目 · HRCT 筛查目标人群自查表

面向已确诊 **弥漫型系统性硬化症（SSc）** 或 **类风湿关节炎（RA）** 患者的手机端自查页面。
患者逐项作答后立即得到「初步符合 / 暂不符合 / 需医生确认」三态结论，并了解报销需要准备的材料。

- 纯静态页面，无后端、无 CDN、无第三方脚本
- **不收集任何个人信息**：所有判定在手机浏览器本地完成，答案只存本机 `localStorage`
- 移动端优先，适配微信内置浏览器、iOS Safari、安卓 WebView
- 结果页可截图留存，结论与报销材料同屏显示

主办方：北京开创者慈善基金会
规则版本：v1.0（生效日期 2026-11-19）

## 一、文件结构

```
index.html          页面骨架（页头 / 进度条 / 页脚）
styles.css          移动优先样式（无外部字体）
logic.js            规则配置 + 判定逻辑（纯函数，可在 Node 中单测）

test/cases.node.js  判定用例（35 条）
.nojekyll           关闭 GitHub Pages 的 Jekyll 处理
```

## 二、判定规则（v1.0）

| 条件 | 结果 |
| --- | --- |
| 年龄 < 18 或 > 75 周岁（按出生日期精确计算） | 暂不符合 |
| 确诊类型只能选 **弥漫型 SSc** 或 **RA** | — |
| SSc：从首次非雷诺症状起算 > 60 个月 | 暂不符合 |
| SSc：≤ 60 个月 | 初步符合 |
| SSc：< 18 个月 | 另加「优先推荐签署」标记 |
| SSc：时间记不清 | 需医生确认 |
| RA：7 项高危因素中确定满足 ≥ 2 项 | 初步符合 |
| RA：确定项 + 待确认项 < 2 项 | 暂不符合 |
| RA：确定项 < 2 但「确定 + 待确认」≥ 2 | 需医生确认 |
| 排除条件任一为「是」 | 暂不符合（一票否决，优先级最高） |
| 排除条件存在「不清楚」 | 需医生确认，并逐条列出 |
| 结论为「暂不符合」 | 不显示报销材料清单 |

优先级：年龄 → 排除条件「是」→ 病程超 5 年 / RA 不足 → 影响结论的「不确定」→ 初步符合。
被排除条件否决时结论为「暂不符合」，但「不清楚」的项目仍会列出，供医生参考。

### RA 的 7 项高危因素

其中 2 项由基本信息自动推导，患者只需回答 5 项：

| 项 | 来源 |
| --- | --- |
| 年龄 > 60 岁 | 自动（出生日期） |
| 男性 | 自动（性别） |
| 有吸烟史 | 提问（从未 / 已戒 / 目前吸） |
| 类风湿因子（RF）升高 | 提问（是 / 否 / 不清楚） |
| 抗 CCP 抗体阳性 | 提问（是 / 否 / 不清楚） |
| 炎症标志物（ESR / CRP）升高 | 提问（是 / 否 / 不清楚） |
| 高疾病活动度 | 提问（是 / 否 / 不清楚） |

## 三、本地预览

```bash
cd HRCT
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

手机预览：同一 Wi-Fi 下访问 `http://<电脑局域网IP>:8080`。

## 四、部署到 GitHub Pages

仓库名：`HRCT`，页面地址：`https://<你的用户名>.github.io/HRCT/`

1. 在 GitHub 新建公开仓库 `HRCT`（免费账号的 Pages 只支持公开仓库）
2. 推送代码到 `main` 分支
3. 仓库 **Settings → Pages → Build and deployment**：Source 选 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存
4. 等待 1–2 分钟，访问上述地址
5. 可选：在 Pages 设置中绑定自定义域名并开启 HTTPS

命令行推送示例（把令牌换成你自己的，不要提交到仓库）：

```bash
git -C HRCT init
git -C HRCT add .
git -C HRCT commit -m "init: 纤护呼吸公益项目 HRCT 自查表 v1.0"
git -C HRCT push https://x-access-token:<TOKEN>@github.com/<用户名>/HRCT.git main
git -C HRCT remote add origin https://github.com/<用户名>/HRCT.git   # 不含令牌
```

> **令牌安全**：使用 fine-grained PAT，只授权 `HRCT` 这一个仓库、Contents 读写权限，有效期尽量短；推送完成后立即吊销。不要把令牌写进任何文件。

## 五、修改规则

所有阈值和题目都在 `logic.js` 顶部的 `RULES` 对象里，改完升 `version` 即可，页面会自动显示新版本号：

```js
raMinFactors: 2,          // RA 高危因素阈值，改成 3 即要求 ≥3 项
sscMaxMonths: 60,         // SSc 病程上限（月）
sscPriorityMonths: 18,    // 「优先推荐签署」的病程界值
ageMin: 18, ageMax: 75,   // 年龄区间
```

排除条件、题干、报销材料清单也都在同一个文件里维护。
改完务必跑一遍用例：

```bash
node test/cases.node.js
```

## 六、隐私说明

- 页面不发任何网络请求，不加载任何第三方统计或字体
- 出生日期、性别、答案只写入本机 `localStorage`，用于刷新后继续填写和结果页勾选状态
- 不收集姓名、电话、证件、银行卡等任何信息，也不提供上传入口
- 患者可随时点击「重新自查」清空本机记录
